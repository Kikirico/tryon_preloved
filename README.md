# Rewear — Preloved with AI Fitting

Laravel 12, Blade, and SQLite. Indonesian storefront with full product detail pages, admin product uploads, private transfer proof verification, and local photo-based FASHN AI Fitting.

See [SETUP.md](SETUP.md) for startup commands, admin setup, payment configuration, AI asset preparation, tests, and limitations.

For local photorealistic FASHN-VTON and the **AI Fitting** navbar, see [FASHN_SETUP.md](FASHN_SETUP.md).

Run the website, local FASHN AI, queue worker, and scheduler together on Windows: `./start.ps1`. Keep the terminal open; press Ctrl+C to stop them. Use `./start.ps1 -WebOnly` to run only the website.
